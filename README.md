This project presents an end-to-end data analysis workflow using Excel, Power BI, and Tableau to uncover insights, identify trends, and support data-driven decision-making. The analysis includes data cleaning, KPI development, dashboard creation, and business insights designed to help stakeholders make informed decisions.

**🎯 Objectives

Clean, standardize, and prepare raw datasets for analysis

Perform exploratory data analysis to identify patterns and correlations

Build interactive dashboards and visualizations

Generate clear, actionable insights for business decision-making

**🛠️ Tools & Technologies

Microsoft Excel (Data cleaning, preprocessing, pivot tables)

Power BI (Interactive dashboards, DAX measures, KPI tracking)

Tableau (Advanced visualizations and storytelling dashboards)

**📂 Project Workflow
1. Data Cleaning (Excel)

Removed duplicates and inconsistent entries

Handled missing values

Normalized and formatted data

Used Pivot Tables, VLOOKUP, and conditional formatting for preprocessing

2. Exploratory Analysis (Excel / Power BI)

Trend analysis

Descriptive statistics

Category and segment comparisons

Identification of key drivers affecting performance

3. Dashboard Development
🔹 Power BI Dashboard

Interactive visualizations

Dynamic filtering using slicers

DAX formulas for KPIs (e.g., YoY %, Growth %, Average Metrics)

Drill-through and page navigation features

🔹 Tableau Dashboard

Advanced charts (line, area, bar, maps, dual-axis, etc.)

Interactive storytelling

Parameter controls for dynamic views

Heatmaps and distribution analysis
